PIXELORA is a UI/UX designer portfolio built with HTML5, Tailwind CSS, and custom animations. Its identity pairs warm neutrals with lavender and coral.

The hero introduces designer Alex Morgan, highlighting a user-focused approach, six+ years of experience, and a creative dashboard visual. The selected work gallery features four projects: Finora Finance, Orbit Analytics, Forma Market, and Studio Bloom, spanning mobile apps, web platforms, e-commerce, and branding.

The about section shares Alex's design philosophy, experience, clients, and achievements. Six service cards cover UI Design, UX Research, Prototyping, Web Design, Design Systems, and Brand Identity.

A four-stage process outlines discovery, exploration, creation, and refinement. The contact section invites project enquiries, while the footer provides navigation, email, and social links.

Built with Tailwind CSS, responsive grids, animated hero elements, floating details, rotating shapes, image zoom, hover transitions, and reduced-motion support, PIXELORA presents a vivid UI portfolio focused on design and user experience.
